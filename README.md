# ListFlow

Sistema de gerenciamento de produtos e controle de estoque.

O ListFlow é uma aplicação web desenvolvida com Python e Flask, que permite gerenciar produtos de maneira simples, prática e organizada.

Sobre o projeto

O objetivo do ListFlow é desenvolver um sistema de gerenciamento de produtos, utilizando operações CRUD e armazenamento de dados com SQLite.

O projeto também busca aplicar conceitos de organização de código, desenvolvimento web e integração com banco de dados.

Como executar o projeto
1. Clone o repositório
bash
git clone https://github.com/victor-sysdev/ListFlow.git

2. Entre na pasta do projeto
bash
cd ListFlow

3. Instale as dependências
bash
pip install Flask

4. Execute a aplicação
bash
python app.py

5. Acesse no navegador
text
http://127.0.0.1:5000/

Banco de dados

O projeto utiliza SQLite3 para armazenar as informações dos produtos.

A tabela principal é chamada produtos e possui os seguintes campos:

id: identificador único do produto.
nome: nome do produto.
valor: preço do produto.

A tabela é criada automaticamente durante a inicialização da aplicação.
